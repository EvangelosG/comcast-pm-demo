# Product backlog

`epics.csv` lists the 25 open epics for the Stream app (fictional backlog written for demos).

| Column | Meaning |
|---|---|
| `epic_id` | Epic key |
| `title`, `description` | What the epic delivers |
| `product_area` | Area of the app |
| `requested_by` | Team that raised it |
| `reach_users_per_quarter` | Estimated viewers affected each quarter |
| `evidence` | What supports the epic today |
| `effort_person_weeks` | Engineering estimate |
| `depends_on` | Epic that must ship first, if any |
| `status` | `Idea`, `Proposed`, `In discovery` or `Committed` |
