# Stream design system

`tokens.css` holds the colours, type sizes, spacing and radii used by the Stream app.

| Component | Rules |
|---|---|
| Title card | 16:9 poster, `--radius-card` corners, title below in `--font-size-md` |
| Progress bar | 4px tall, `--color-brand` fill on `--color-surface-raised`, sits on the bottom edge of the poster |
| Row | Heading in `--font-size-lg`, horizontally scrolling cards, `--space-3` gap |
| Primary button | `--color-brand` background, white text, `--radius-pill` |
| Device chip | Pill with the device name; the active chip uses `--color-brand` |

Tone of voice: short, plain and friendly. "Pick up where you left off", not "Resume playback session".
